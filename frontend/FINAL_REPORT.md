## 🎓 技术文档

### 运行命令

```bash
# 开发模式
npm run dev

# 生产构建
npm run build

# 预览构建
npm run preview

# 使用启动脚本
./start.sh              # 开发模式
./start.sh --build      # 构建
./start.sh --preview    # 预览
```

### 添加新组件

```bash
# 1. 创建组件文件
cd src/components/sections
touch NewSection.tsx

# 2. 在 App.tsx 中引入
import NewSection from './components/sections/NewSection'
```
