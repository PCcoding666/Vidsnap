# 千问API参数修改记录

## 2025年4月8日 - 删除max_tokens参数

### 修改原因
在调用千问API时，如果`max_tokens`参数超出API允许的范围（[1, 2048]），会返回400错误。为了简化API调用并避免这个参数引起的问题，我们决定完全移除此参数，使用API的默认值。

### 修改文件
1. `/app/services/summary/qwen_service_part2.py`
   - 从API请求中移除`max_tokens`参数
   - 受影响的方法：`_check_availability`, `generate_summary_from_frames`, `generate_summary_from_video`

2. `/tests/test_qwen_direct.py`
   - 从测试请求中移除`max_tokens`参数

3. `/tests/test_qwen_integration.py`
   - 从集成测试中移除`max_tokens`参数

4. `/tests/docs/qwen_api_format.md`
   - 更新文档，反映移除`max_tokens`参数的修改
   - 添加关于模型限制的注意事项

### 测试结果
- 直接API调用测试成功
- 集成测试成功
- 验证API能够使用默认token限制正确响应

### 注意事项
- 千问API会根据模型自动使用合适的默认token生成限制
- 如果需要精确控制输出长度，可以在提示词中指定要求
