## 🔧 故障排除速查表

| 错误 | 原因 | 解决方法 |
|------|------|---------|
| `ModuleNotFoundError: pytest` | pytest未安装 | `pip install pytest pytest-asyncio` |
| `FileNotFoundError: ffmpeg` | ffmpeg未安装 | `brew install ffmpeg` (macOS) |
| `缺少环境变量` | .env未配置 | 创建.env文件并配置OSS信息 |
| `YouTube下载失败` | yt-dlp版本过旧 | `pip install --upgrade yt-dlp` |
| `OSS连接失败` | 凭证错误 | 检查Access Key和Endpoint |
| `URL不可访问` | Bucket权限问题 | 设置Bucket为公共读 |
| `测试超时` | 网络慢 | 增加NETWORK_TIMEOUT值 |
