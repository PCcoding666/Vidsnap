## 🔧 主要修改

### 1. 导入聊天服务
```python
from app.services.chat_service import video_chat_service
```

### 2. 添加全局状态变量
```python
current_chat_session_id: Optional[str] = None
current_video_metadata: Optional[dict] = None
current_video_id: Optional[str] = None
```

### 3. 新增功能函数

#### `start_chat_session()` - 启动聊天会话
- 自动使用处理完的视频 metadata
- 返回会话状态和信息

#### `ask_question(question, history)` - 提问
- 调用后端 chat API
- 返回更新后的对话历史和引用信息
- 自动格式化时间范围和关键帧引用

### 4. UI 组件

添加了以下组件：

**控制区域**：
- `chat_start_btn` - 启动聊天会话按钮
- `chat_status` - 会话状态显示
- `chat_info` - 会话信息显示

**对话区域**：
- `chatbot` - 对话历史展示（Gradio Chatbot 组件）
- `question_input` - 问题输入框
- `send_btn` - 发送按钮
- `chat_references` - 引用信息显示

**辅助功能**：
- `clear_chat_btn` - 清空对话按钮
- 使用提示说明

### 5. 事件绑定

- ✅ 启动会话：`chat_start_btn.click()`
- ✅ 发送问题：`send_btn.click()` 和 `question_input.submit()`
- ✅ 清空对话：`clear_chat_btn.click()`
- ✅ 自动清空输入框：发送后清空

## 📊 数据流

```
用户上传/输入视频
    ↓
处理视频（pipeline）
    ↓
保存 metadata 到全局变量
    ↓
用户点击"启动聊天会话"
    ↓
调用 video_chat_service.start_session()
    ↓
获得 session_id
    ↓
用户在聊天框提问
    ↓
调用 video_chat_service.ask_question()
    ↓
显示回答 + 引用信息（时间范围、关键帧）
    ↓
支持多轮对话...
```

## 🚀 使用流程

### 第一步：处理视频
1. 在"输入与配置"标签页上传视频或输入 YouTube URL
2. 点击"开始分析"
3. 等待处理完成

### 第二步：启动聊天
1. 切换到"结果展示"标签页
2. 滚动到底部"与视频对话"区域
3. 点击"启动聊天会话"按钮
4. 查看会话信息确认成功

### 第三步：开始对话
1. 在输入框中输入问题
2. 点击"发送"或按 Enter 键
3. 查看 AI 回答和引用信息
4. 继续提问进行多轮对话

## 📝 示例对话

### 场景 1：时间定位
```
👤 用户: 视频中在哪里讲了数据分析的重要性？

🤖 助手: 根据提供的转录文本，视频中在 00:06 左右开始讲解数据分析的重要性...

📌 引用信息:
🕒 相关时间段:
  • 00:05 - 00:10: 首先，让我们了解一下什么是数据分析...
  • 00:10 - 00:15: 数据分析可以帮助我们从大量数据中...
```

### 场景 2：内容总结
```
👤 用户: 这个视频主要讲什么内容？

🤖 助手: 这个视频主要介绍 Python 数据分析的基础知识，包括 pandas 库的使用、数据加载和清洗等内容。

📌 引用信息:
🕒 相关时间段:
  • 00:00 - 00:05: 欢迎来到今天的视频教程...
  • 00:15 - 00:22: 接下来我们将介绍pandas库...

💬 对话轮数: 1
```

### 场景 3：多轮对话
```
👤 用户: 这个视频主要讲什么？
🤖 助手: 这个视频主要介绍 Python 数据分析...

👤 用户: 能详细说说 pandas 部分吗？
🤖 助手: pandas 部分在视频的 15:30 开始，主要包括...

👤 用户: 这部分大概在什么时间？
🤖 助手: 根据提供的转录文本，这部分内容大约在视频的 00:15 - 00:30 时间段...
```

## ⚙️ 配置要求

### 必需环境变量
```bash
QWEN_API_KEY=sk-xxx...  # 通义千问 API Key
```

### 可选配置
在 `chat_service.py` 中：
- `top_k = 5` - 检索片段数量
- `max_length = 800` - LLM 最大输出长度
- `auto_keyframes = False` - 是否自动匹配关键帧
