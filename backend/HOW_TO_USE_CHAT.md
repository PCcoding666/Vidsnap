# 💬 如何使用 Chat with Video 功能

## 🚀 快速开始（3步）

### 步骤 1：启动 FastAPI 后端

```bash
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

在浏览器中打开：http://localhost:7860

---

### 步骤 2：处理视频

1. **选择输入方式**
   - YouTube URL：输入视频链接
   - 本地上传：上传 MP4/AVI/MOV/MKV 文件

2. **设置参数**（可选）
   - 语言：自动检测/中文/英文/韩文
   - 总结粒度：简要/标准/详细
   - 关键帧数量：5-20

3. **点击"开始分析"**
   - 等待处理完成（1-5分钟）
   - 在"结果展示"标签页查看结果

---

### 步骤 3：开始对话

1. **切换到"结果展示"标签页**
2. **滚动到底部"💬 与视频对话"区域**
3. **点击"🚀 启动聊天会话"按钮**
4. **等待会话启动（2-3秒）**
5. **在输入框中输入问题，点击"发送"**
6. **查看 AI 回答和引用信息**

---

## 🎯 功能特性

### ✅ 智能时间定位
- 自动从转录中检索相关片段
- 返回具体的时间范围（MM:SS格式）
- 支持多个时间段引用

### ✅ 多轮对话
- 保留最近4轮对话上下文
- 支持连续追问
- 理解上下文语义

### ✅ 引用信息
显示以下信息：
- 🕒 相关时间段（开始-结束）
- 🖼️ 使用的关键帧
- 💬 对话轮数

## ⚠️ 注意事项

### 1. 必须先处理视频
- 聊天功能依赖视频处理结果
- 确保在"结果展示"看到内容后再启动聊天

### 2. API Key 配置
```bash
# 确保设置了环境变量
export QWEN_API_KEY=sk-xxx...
```

### 3. 会话管理
- 每个视频需要单独启动会话
- 处理新视频后需要重新启动会话
- 服务重启后会话会丢失

### 4. 响应时间
- 首次提问：约3-5秒
- 后续提问：约2-3秒
- 取决于网络和 API 响应速度

## 🔧 故障排查

### 问题 1："请先处理视频后再启动聊天会话"
**解决**：在"输入与配置"标签页处理视频，等待完成

### 问题 2："LLM 服务不可用"
**解决**：检查 `QWEN_API_KEY` 环境变量是否设置

### 问题 3："会话不存在"
**解决**：点击"启动聊天会话"按钮重新启动

### 问题 4：回答不准确
**解决**：
- 尝试更详细的问题描述
- 包含更多关键词
- 使用多轮对话澄清

## 📖 使用技巧

### 1. 提问技巧
✅ **好的问题**：
- "视频中在哪里讲了数据分析的重要性？"
- "关于pandas库的内容在什么时间段？"
- "视频主要介绍了哪些数据分析工具？"

❌ **不好的问题**：
- "好"（过于简短）
- "XXX"（不明确）
- "讲得怎么样"（主观性问题）

### 2. 多轮对话技巧
- 第1轮：先问总体问题（"主要讲什么？"）
- 第2轮：深入某个话题（"详细说说XXX"）
- 第3轮：定位具体内容（"这在什么时间？"）

### 3. 利用引用信息
- 查看时间范围快速定位视频片段
- 根据关键帧了解视觉内容
- 结合对话轮数掌握对话进度

## ❓ 常见问题

**Q: 可以同时对多个视频聊天吗？**  
A: 当前版本不支持，每次只能对一个视频聊天。处理新视频后需要重新启动会话。

**Q: 对话历史会保存吗？**  
A: 当前在内存中保存，刷新页面或重启服务会丢失。

**Q: 支持语音输入吗？**  
A: 当前版本不支持，需要手动输入文字。

**Q: 可以指定关键帧进行视觉问答吗？**  
A: 当前版本自动禁用了关键帧功能，等待后续版本支持。

**Q: 回答的时间范围准确吗？**  
A: 基于转录文本的时间戳，准确度取决于转录质量。
