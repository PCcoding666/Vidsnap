## 🚀 快速开始

### 系统要求

- **操作系统**: macOS / Linux / Windows
- **Python**: 3.8 或更高版本
- **内存**: 至少 4GB RAM
- **网络**: 稳定的互联网连接（用于访问阿里云 API）
- **浏览器**: Chrome / Firefox / Safari / Edge（最新版本）

### 安装步骤

#### 1. 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

确保安装了以下核心依赖：
- `gradio>=4.0.0` - Web 界面框架
- `fastapi>=0.100.0` - API 框架
- `oss2>=2.18.0` - 阿里云 OSS SDK
- `dashscope>=1.14.0` - 阿里云 DashScope SDK

#### 2. 环境变量配置

在项目根目录创建 `.env` 文件并配置以下变量：

```bash
# 阿里云 OSS 配置（必需）
OSS_ACCESS_KEY_ID=your_access_key_id
OSS_ACCESS_KEY_SECRET=your_access_key_secret
OSS_BUCKET=your_bucket_name
OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com

# API 密钥配置（至少配置一个）
QWEN_API_KEY=your_qwen_api_key                           # 推荐：用于 SenseVoice 和 Qwen VL
DASHSCOPE_API_KEY=your_dashscope_api_key                 # 备选：兼容旧配置
TRANSCRIPT_SERVICE_API_KEY=your_transcript_api_key       # 最高优先级

# 可选配置
LOG_LEVEL=INFO
```

**API 密钥优先级**：
1. `TRANSCRIPT_SERVICE_API_KEY`（最高优先级）
2. `QWEN_API_KEY`（推荐使用）
3. `DASHSCOPE_API_KEY`（向后兼容）

#### 3. 启动应用

**方式一：使用启动脚本（推荐）**

```bash
cd backend
chmod +x run_gradio.sh
./run_gradio.sh
```

**方式二：直接运行 Python**

```bash
cd backend
export https_proxy=http://127.0.0.1:33210
export http_proxy=http://127.0.0.1:33210
export all_proxy=socks5://127.0.0.1:33211
python3 gradio_app.py
```

#### 4. 访问界面

启动成功后，在浏览器中访问：
- **本地访问**: http://127.0.0.1:7860
- **网络访问**: http://0.0.0.0:7860

### 启动选项

```bash
# 默认启动
./run_gradio.sh

# 生成公网链接（用于远程访问）
./run_gradio.sh --share

# 自定义端口
./run_gradio.sh --port 8080

# 自定义主机
./run_gradio.sh --host 127.0.0.1

# 查看帮助
./run_gradio.sh --help
```

## 📖 功能说明

### 1️⃣ 输入方式

系统支持两种视频输入方式：

#### YouTube URL 模式

**支持的 URL 格式**：
- 标准格式: `https://www.youtube.com/watch?v=VIDEO_ID`
- 短链接: `https://youtu.be/VIDEO_ID`
- 短视频: `https://www.youtube.com/shorts/VIDEO_ID`
- 移动端: `https://m.youtube.com/watch?v=VIDEO_ID`

**使用步骤**：
1. 选择"YouTube URL"模式
2. 粘贴视频链接到输入框
3. 配置处理参数
4. 点击"开始分析"

**注意事项**：
- 确保视频可公开访问（非私有视频）
- 年龄限制视频可能无法下载
- 版权保护视频可能被阻止

#### 本地视频上传模式

**支持的文件格式**：
- MP4 (推荐)
- AVI
- MOV
- MKV

**文件大小限制**: 500MB

**使用步骤**：
1. 选择"本地视频上传"模式
2. 点击上传区域选择文件
3. 等待文件上传完成
4. 配置处理参数
5. 点击"开始分析"

**注意事项**：
- 推荐使用 MP4 格式（兼容性最佳）
- 文件过大可能导致处理时间较长
- 确保视频文件未损坏

### 2️⃣ 处理参数详解

#### 语言选择

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| **自动检测** | 系统自动识别视频语言 | 推荐，适用于大多数情况 |
| **中文** | 强制使用中文模型 | 纯中文内容 |
| **英文** | 强制使用英文模型 | 纯英文内容 |
| **韩文** | 强制使用韩文模型 | 纯韩文内容 |

**建议**: 除非明确知道视频语言，否则使用"自动检测"

#### 总结粒度

| 粒度 | 长度 | 内容 | 适用场景 |
|------|------|------|----------|
| **简要** | 1-2 句话 | 核心概括 | 快速了解视频主题 |
| **标准** | 段落级 | 主要内容要点 | 日常使用（推荐） |
| **详细** | 分段详解 | 深度分析 + 时间线 | 需要深入理解内容 |

**处理时间对比**：
- 简要: 最快
- 标准: 适中（推荐）
- 详细: 最慢（约 1.5-2 倍时间）

#### 关键帧数量

- **范围**: 5-20 帧
- **默认**: 10 帧
- **建议**:
  - 短视频（<5分钟）: 5-8 帧
  - 中等视频（5-15分钟）: 10-15 帧
  - 长视频（>15分钟）: 15-20 帧

**影响**：
- 更多帧 → 更详细的视觉分析，但处理时间更长
- 更少帧 → 更快的处理速度，但可能遗漏细节

### 3️⃣ 结果展示说明

处理完成后，在"结果展示"标签页查看：

#### 📝 简要总结
- **位置**: 左上方蓝色卡片
- **内容**: 1-2 句话概括视频核心内容
- **用途**: 快速了解视频主题

#### 📖 标准总结
- **位置**: 左侧紫色卡片
- **内容**: 段落级详细描述，包含主要内容要点
- **用途**: 全面理解视频内容

#### 📚 详细总结
- **位置**: 左侧橙色卡片
- **内容**: 分段落的深度分析，包含时间线信息
- **用途**: 深入研究视频内容（仅在选择"详细"粒度时显示）

#### 🎤 音频转录
- **位置**: 左下方
- **格式**: `[开始时间 - 结束时间] 文本内容`
- **功能**:
  - 完整的带时间戳转录
  - 可复制文本
  - 支持搜索（浏览器 Ctrl+F）

#### 🖼️ 关键帧展示
- **位置**: 右上方
- **布局**: 3 列网格
- **信息**: 每张图片显示帧序号、时间戳和 AI 描述
- **交互**: 点击可放大查看

#### ℹ️ 视频信息
- 标题、时长、视频ID
- 处理时间、语言
- 分辨率、文件大小

#### 💾 下载资源
- 原视频（OSS 链接）
- 音频文件（OSS 链接）
- 元数据 JSON（OSS 链接）

## 💡 使用技巧

### 最佳实践

#### 1. 视频长度建议

| 视频长度 | 推荐度 | 说明 |
|----------|--------|------|
| < 2 分钟 | ⭐⭐⭐ | 快速处理，适合测试 |
| 2-15 分钟 | ⭐⭐⭐⭐⭐ | **最佳范围**，效果最好 |
| 15-30 分钟 | ⭐⭐⭐⭐ | 处理时间较长，但效果良好 |
| > 30 分钟 | ⭐⭐ | 耗时较长，建议分段处理 |

#### 2. 语言选择建议

- **多语言视频**: 选择"自动检测"
- **纯中文视频**: 可选"中文"以提高准确度
- **英文教程**: 选择"英文"
- **混合语言**: 使用"自动检测"

#### 3. 关键帧数量选择

```
视频时长 (分钟) -> 推荐帧数
0-3      -> 5-8 帧
3-10     -> 10-12 帧
10-20    -> 15-18 帧
20+      -> 18-20 帧
```

#### 4. 粒度选择策略

- **快速浏览**: 选择"简要"
- **日常使用**: 选择"标准"（推荐）
- **学习研究**: 选择"详细"
- **会议记录**: 选择"详细" + 20 帧

## ❓ 常见问题 (FAQ)

### Q1: 处理时间需要多久？

**A**: 取决于视频长度和参数设置：

| 视频长度 | 简要粒度 | 标准粒度 | 详细粒度 |
|----------|----------|----------|----------|
| 2 分钟   | ~1 分钟  | ~1.5 分钟 | ~2 分钟   |
| 5 分钟   | ~2 分钟  | ~3 分钟  | ~4 分钟   |
| 10 分钟  | ~3 分钟  | ~5 分钟  | ~7 分钟   |
| 20 分钟  | ~5 分钟  | ~8 分钟  | ~12 分钟  |

**影响因素**:
- 网络速度（YouTube 下载）
- 视频分辨率
- 关键帧数量
- API 响应速度

### Q2: 支持哪些视频类型？

**A**: 
- ✅ 教程视频
- ✅ 会议录像
- ✅ 新闻报道
- ✅ 演讲视频
- ✅ 产品评测
- ⚠️ 纯音乐视频（转录效果有限）
- ❌ 无音频视频（仅关键帧分析）

### Q3: 为什么处理失败？

**常见原因及解决方法**：

#### 网络错误
- **症状**: "网络连接失败"
- **解决**: 
  - 检查网络连接
  - 确认代理设置正确
  - 稍后重试

#### YouTube 下载失败
- **症状**: "视频不可用"或"下载失败"
- **解决**:
  - 检查视频链接是否正确
  - 确认视频未被删除或设为私有
  - 尝试使用"本地上传"模式

#### API 调用错误
- **症状**: "API 密钥无效"或"配额超限"
- **解决**:
  - 检查 `.env` 文件中的 API 密钥
  - 确认 API 账户余额充足
  - 检查是否超出每日配额

#### 文件格式错误
- **症状**: "文件格式不支持"
- **解决**:
  - 确保文件是 MP4/AVI/MOV/MKV 格式
  - 尝试转换为 MP4 格式
  - 检查文件是否损坏

### Q4: 如何提高转录准确度？

**建议**:
1. 选择音频清晰的视频
2. 避免背景噪音过大的视频
3. 中文内容选择"中文"语言
4. 使用高质量的视频源

### Q5: 生成的总结不准确怎么办？

**优化方法**:
1. 增加关键帧数量（提供更多视觉信息）
2. 选择更高的粒度级别
3. 确保转录准确（转录是总结的基础）
4. 尝试分段处理长视频

### Q6: 可以处理本地摄像头录制的视频吗？

**A**: 可以！只要文件格式是 MP4/AVI/MOV/MKV，且文件小于 500MB。

### Q7: 处理后的文件保存在哪里？

**A**: 所有文件上传到阿里云 OSS，包括：
- 原视频
- 提取的音频
- 关键帧图片
- 元数据 JSON

可以通过"下载资源"区域的链接访问。

### Q8: 支持批量处理吗？

**A**: 当前版本不支持批量处理。如需处理多个视频，请逐个提交。

## 🔧 故障排查

### 启动问题

#### 问题: 找不到 gradio 模块
```bash
ModuleNotFoundError: No module named 'gradio'
```
**解决**:
```bash
pip install gradio>=4.0.0
```

#### 问题: 端口被占用
```bash
OSError: [Errno 48] Address already in use
```
**解决**:
```bash
# 使用不同端口
./run_gradio.sh --port 8080

# 或终止占用进程
lsof -ti:7860 | xargs kill -9
```

### 处理问题

#### 问题: OSS 上传失败
**检查**:
- OSS 配置是否正确
- Access Key 是否有效
- Bucket 是否存在且可访问

#### 问题: API 调用超时
**检查**:
- 网络连接是否稳定
- 代理设置是否正确
- API 服务是否正常
