# File Organization Rules

## Test Scripts (.sh files)
- All test scripts with `.sh` extension should be placed in the `app/tests/` directory
- Naming convention: Use descriptive names that reflect the test purpose

- All status documentation and test-related markdown files should be created in the `app/tests/docs/` directory
- Naming convention: Use clear, descriptive names (e.g., `test_status.md`, `test_results.md`)
