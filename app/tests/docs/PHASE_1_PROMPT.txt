# YouTube 视频智能总结系统 - 阶段一开发提示词

## 项目背景

这是一个基于阿里云 AI 服务的 YouTube 视频智能总结 SaaS 系统。当前状态：
- **后端**：FastAPI (端口 8000) + Gradio 原型 (端口 7860)，已完成核心业务逻辑
- **前端**：React + TypeScript + Vite (端口 8080)，仅有展示页面，未连接后端
- **数据库**：Supabase (已集成认证和数据持久化)

## 阶段一目标

建立 React 前端与 FastAPI 后端的完整数据流，实现前后端打通。预计 2-3 周完成。

#### 1.1 创建统一的 HTTP 客户端

**文件路径**: `frontend/src/lib/api/client.ts`

**需求**:
1. 基于 axios 创建统一的 HTTP 客户端实例
2. 配置基础 URL (从环境变量读取: `VITE_API_BASE_URL`)
3. 实现请求拦截器：自动注入 Authorization Token
4. 实现响应拦截器：统一错误处理、Token 过期自动刷新
5. 导出类型安全的 API 客户端

**技术要求**:
- 使用 TypeScript 严格类型
- Token 从 localStorage 读取 (key: `auth_token`)
- Token 刷新失败时清除本地存储并跳转登录
- 错误处理要覆盖网络错误、4xx、5xx

**参考结构**:
```typescript
import axios from 'axios';

const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || 'http://localhost:8000';

const apiClient = axios.create({
  baseURL: API_BASE_URL,
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// 请求拦截器
apiClient.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('auth_token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);

// 响应拦截器
apiClient.interceptors.response.use(
  (response) => response,
  async (error) => {
    // 处理 401 错误、Token 刷新逻辑
    // 处理其他错误
    return Promise.reject(error);
  }
);

export default apiClient;
```

#### 1.3 创建认证 API 模块

**文件路径**: `frontend/src/lib/api/auth.ts`

**需求**:
封装所有认证相关的 API 调用，包括：

1. 邮箱注册 `signUp()`
2. 邮箱登录 `signIn()`
3. 获取当前用户信息 `getCurrentUser()`
4. 获取 Google OAuth URL `getGoogleOAuthUrl()`
5. 处理 OAuth 回调 `handleOAuthCallback()`

**技术要求**:
- 使用 apiClient 发送请求
- 所有函数返回 Promise
- 使用前面定义的类型
- 成功时自动保存 Token 到 localStorage

**参考结构**:
```typescript
import apiClient from './client';
import type { 
  SignUpRequest, 
  SignInRequest, 
  AuthResponse,
  UserResponse,
  OAuthURLResponse 
} from './types';

export const authApi = {
  async signUp(data: SignUpRequest): Promise<AuthResponse> {
    const response = await apiClient.post<AuthResponse>('/auth/signup', data);
    localStorage.setItem('auth_token', response.data.access_token);
    localStorage.setItem('refresh_token', response.data.refresh_token);
    return response.data;
  },

  async signIn(data: SignInRequest): Promise<AuthResponse> {
    const response = await apiClient.post<AuthResponse>('/auth/signin', data);
    localStorage.setItem('auth_token', response.data.access_token);
    localStorage.setItem('refresh_token', response.data.refresh_token);
    return response.data;
  },

  async getCurrentUser(): Promise<UserResponse> {
    const response = await apiClient.get<UserResponse>('/auth/me');
    return response.data;
  },

  async getGoogleOAuthUrl(redirectUrl: string): Promise<OAuthURLResponse> {
    const response = await apiClient.get<OAuthURLResponse>(
      `/auth/oauth/google?redirect_url=${encodeURIComponent(redirectUrl)}`
    );
    return response.data;
  },

  async handleOAuthCallback(code: string): Promise<AuthResponse> {
    const response = await apiClient.post<AuthResponse>('/auth/oauth/callback', { code });
    localStorage.setItem('auth_token', response.data.access_token);
    localStorage.setItem('refresh_token', response.data.refresh_token);
    return response.data;
  },

  logout() {
    localStorage.removeItem('auth_token');
    localStorage.removeItem('refresh_token');
  },
};
```

```typescript
import apiClient from './client';
import type { VideoProcessResponse, ServiceStatus } from './types';

export const videoApi = {
  async processVideo(params: {
    youtubeUrl?: string;
    videoFile?: File;
    onUploadProgress?: (progress: number) => void;
  }): Promise<VideoProcessResponse> {
    const formData = new FormData();
    
    if (params.youtubeUrl) {
      formData.append('youtube_url', params.youtubeUrl);
    }
    
    if (params.videoFile) {
      formData.append('video_file', params.videoFile);
    }
    
    const response = await apiClient.post<VideoProcessResponse>(
      '/video/process',
      formData,
      {
        headers: {
          'Content-Type': 'multipart/form-data',
        },
        onUploadProgress: (progressEvent) => {
          if (params.onUploadProgress && progressEvent.total) {
            const progress = (progressEvent.loaded / progressEvent.total) * 100;
            params.onUploadProgress(progress);
          }
        },
      }
    );
    
    return response.data;
  },

  async getServiceStatus(): Promise<ServiceStatus> {
    const response = await apiClient.get<ServiceStatus>('/video/status');
    return response.data;
  },
};
```

### 任务 2：实现认证状态管理

#### 2.1 创建认证 Context

**文件路径**: `frontend/src/contexts/AuthContext.tsx`

**需求**:
1. 提供全局认证状态管理
2. 封装登录、注册、登出逻辑
3. 自动检查用户登录状态
4. 提供 loading 状态

**技术要求**:
- 使用 React Context API
- 页面加载时自动从 localStorage 恢复登录状态
- Token 存在时自动调用 `/auth/me` 验证
- 提供类型安全的 useAuth Hook

**参考结构**:
```typescript
import React, { createContext, useContext, useState, useEffect, ReactNode } from 'react';
import { authApi } from '@/lib/api/auth';
import type { UserResponse } from '@/lib/api/types';

interface AuthContextType {
  user: UserResponse | null;
  isAuthenticated: boolean;
  isLoading: boolean;
  signIn: (email: string, password: string) => Promise<void>;
  signUp: (email: string, password: string, username?: string) => Promise<void>;
  logout: () => void;
  refreshUser: () => Promise<void>;
}

const AuthContext = createContext<AuthContextType | undefined>(undefined);

export const AuthProvider: React.FC<{ children: ReactNode }> = ({ children }) => {
  const [user, setUser] = useState<UserResponse | null>(null);
  const [isLoading, setIsLoading] = useState(true);

  // 初始化时检查登录状态
  useEffect(() => {
    const initAuth = async () => {
      const token = localStorage.getItem('auth_token');
      if (token) {
        try {
          const userData = await authApi.getCurrentUser();
          setUser(userData);
        } catch (error) {
          console.error('Token 验证失败:', error);
          authApi.logout();
        }
      }
      setIsLoading(false);
    };

    initAuth();
  }, []);

  const signIn = async (email: string, password: string) => {
    const response = await authApi.signIn({ email, password });
    setUser(response.user);
  };

  const signUp = async (email: string, password: string, username?: string) => {
    const response = await authApi.signUp({ email, password, username });
    setUser(response.user);
  };

  const logout = () => {
    authApi.logout();
    setUser(null);
  };

  const refreshUser = async () => {
    const userData = await authApi.getCurrentUser();
    setUser(userData);
  };

  const value = {
    user,
    isAuthenticated: !!user,
    isLoading,
    signIn,
    signUp,
    logout,
    refreshUser,
  };

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
};

export const useAuth = () => {
  const context = useContext(AuthContext);
  if (context === undefined) {
    throw new Error('useAuth must be used within an AuthProvider');
  }
  return context;
};
```

```typescript
import { useEffect } from 'react';
import { useNavigate, useSearchParams } from 'react-router-dom';
import { authApi } from '@/lib/api/auth';
import { useAuth } from '@/contexts/AuthContext';
import { useToast } from '@/hooks/use-toast';

export default function AuthCallback() {
  const [searchParams] = useSearchParams();
  const navigate = useNavigate();
  const { refreshUser } = useAuth();
  const { toast } = useToast();

  useEffect(() => {
    const handleCallback = async () => {
      const code = searchParams.get('code');
      
      if (!code) {
        toast({
          title: 'OAuth 授权失败',
          description: '未获取到授权码',
          variant: 'destructive',
        });
        navigate('/login');
        return;
      }

      try {
        await authApi.handleOAuthCallback(code);
        await refreshUser();
        toast({ title: '登录成功' });
        navigate('/dashboard');
      } catch (error: any) {
        toast({
          title: 'OAuth 认证失败',
          description: error.response?.data?.detail || '认证失败',
          variant: 'destructive',
        });
        navigate('/login');
      }
    };

    handleCallback();
  }, [searchParams, navigate, refreshUser, toast]);

  return (
    <div className="min-h-screen flex items-center justify-center">
      <div className="text-center">
        <div className="animate-spin rounded-full h-12 w-12 border-b-2 border-primary mx-auto mb-4"></div>
        <p className="text-muted-foreground">正在处理登录...</p>
      </div>
    </div>
  );
```

```typescript
      const response = await videoApi.processVideo({
        youtubeUrl: inputMode === 'url' ? youtubeUrl : undefined,
        videoFile: inputMode === 'upload' ? videoFile : undefined,
        onUploadProgress: setUploadProgress,
      });

      setResult(response);
      toast({ title: '处理完成！' });
    } catch (error: any) {
      toast({
        title: '处理失败',
        description: error.response?.data?.detail || error.message,
        variant: 'destructive',
      });
    } finally {
      setIsProcessing(false);
    }
  };

  return (
    <div className="max-w-6xl mx-auto space-y-6">
      <h1 className="text-3xl font-bold">视频处理</h1>

      <Card className="p-6">
        <Tabs value={inputMode} onValueChange={(v) => setInputMode(v as any)}>
          <TabsList className="grid w-full grid-cols-2">
            <TabsTrigger value="url">YouTube URL</TabsTrigger>
            <TabsTrigger value="upload">本地上传</TabsTrigger>
          </TabsList>

          <TabsContent value="url" className="space-y-4">
            <Input
              placeholder="https://www.youtube.com/watch?v=..."
              value={youtubeUrl}
              onChange={(e) => setYoutubeUrl(e.target.value)}
            />
          </TabsContent>

          <TabsContent value="upload" className="space-y-4">
            <Input
              type="file"
              accept="video/mp4,video/avi,video/mov,video/mkv"
              onChange={(e) => setVideoFile(e.target.files?.[0] || null)}
            />
          </TabsContent>
        </Tabs>

        <Button
          className="w-full mt-4"
          onClick={handleSubmit}
          disabled={isProcessing}
        >
          {isProcessing ? `处理中 (${uploadProgress.toFixed(0)}%)...` : '开始分析'}
        </Button>
      </Card>

      {/* 结果展示区域 */}
      {result && (
        <div className="grid grid-cols-1 lg:grid-cols-2 gap-6">
          {/* 总结 */}
          <Card className="p-6">
            <h2 className="text-xl font-bold mb-4">视频总结</h2>
            <div className="prose">
              {result.video_summary?.detailed_summary}
            </div>
          </Card>

          {/* 转录 */}
          <Card className="p-6">
            <h2 className="text-xl font-bold mb-4">音频转录</h2>
            <div className="space-y-2 max-h-96 overflow-y-auto">
              {result.metadata.transcript?.segments.map((seg, idx) => (
                <div key={idx} className="text-sm">
                  <span className="text-muted-foreground">
                    [{formatTime(seg.start_time)}]
                  </span>{' '}
                  {seg.text}
                </div>
              ))}
            </div>
          </Card>

          {/* 关键帧 */}
          <Card className="p-6 lg:col-span-2">
            <h2 className="text-xl font-bold mb-4">关键帧</h2>
            <div className="grid grid-cols-3 gap-4">
              {result.metadata.keyframes?.map((kf) => (
                <div key={kf.frame_id}>
                  <img
                    src={kf.oss_image_url}
                    alt={kf.scene_description}
                    className="rounded-lg w-full"
                  />
                  <p className="text-xs text-muted-foreground mt-2">
                    {kf.scene_description}
                  </p>
                </div>
              ))}
            </div>
          </Card>
        </div>
      )}
    </div>
  );
}

function formatTime(seconds: number): string {
  const mins = Math.floor(seconds / 60);
  const secs = Math.floor(seconds % 60);
  return `${mins}:${secs.toString().padStart(2, '0')}`;
}
```
