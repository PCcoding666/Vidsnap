# 阶段一前后端打通测试指引

## 测试目标

验证React前端与FastAPI后端的完整数据流通道，确保用户认证、视频处理请求提交、处理结果展示等核心功能正常工作。

## 测试前准备

### 1. 环境检查

确保以下服务已安装：
- Node.js >= 18
- Python >= 3.9
- npm 或 bun

### 2. 环境变量配置

确保项目根目录的`.env`文件已配置完整：

```bash
# Supabase配置
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key

# Google OAuth配置
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# 阿里云配置
ALIBABA_CLOUD_ACCESS_KEY_ID=your_access_key
ALIBABA_CLOUD_ACCESS_KEY_SECRET=your_secret_key
OSS_BUCKET_NAME=your_bucket_name
OSS_ENDPOINT=your_oss_endpoint

# 其他配置...
```

### 3. 启动服务

#### 启动后端服务（端口8000）

```bash
./app/tests/run_fastapi.sh
```

等待看到：
```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete.
```

#### 启动前端服务（端口8080）

在新终端窗口执行：
```bash
./app/tests/run_frontend.sh
```

等待看到：
```
VITE ready in xxx ms
➜  Local:   http://localhost:8080/
```

## 测试工具

### 浏览器开发者工具检查

1. **Network标签**
   - 检查API请求是否正确发送
   - 查看请求头是否包含Authorization Token
   - 确认响应状态码和数据格式

2. **Console标签**
   - 检查是否有JavaScript错误
   - 查看API调用日志

3. **Application标签**
   - 检查localStorage中的Token存储
   - 验证Token在登出后被清除

### 推荐测试浏览器

- Chrome/Edge（主要测试）
- Firefox（兼容性测试）
- Safari（Mac用户）
- 移动端浏览器（响应式测试）

## 常见问题排查

### 前端无法连接后端

**症状**: API请求显示CORS错误或连接被拒绝

**排查步骤**:
1. 确认后端服务正在运行（端口8000）
2. 检查 vite.config.ts 中的proxy配置
3. 检查 frontend/.env 中的 VITE_API_BASE_URL

### Google OAuth无法使用

**症状**: 点击Google登录没有反应或报错

**排查步骤**:
1. 确认后端 .env 中配置了 GOOGLE_CLIENT_ID 和 GOOGLE_CLIENT_SECRET
2. 检查Google Cloud Console中的重定向URI配置
3. 查看浏览器Console的错误信息

### Token验证失败

**症状**: 登录后访问Dashboard仍然跳转到登录页

**排查步骤**:
1. 打开浏览器开发者工具 -> Application -> Local Storage
2. 确认有 auth_token 和 refresh_token
3. 查看Network标签，检查 /auth/me 请求的响应
