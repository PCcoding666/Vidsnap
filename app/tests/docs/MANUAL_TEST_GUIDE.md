## 🧪 测试场景

### 场景 1: 后端 Gradio 界面测试

#### 访问地址
```
http://127.0.0.1:7860
```

#### 测试步骤

**1️⃣ YouTube 视频分析**

1. 打开 Gradio 界面
2. 选择「📥 输入与配置」标签页
3. 选择输入方式：`YouTube URL`
4. 输入测试视频链接（推荐短视频）：
   ```
   https://www.youtube.com/watch?v=dQw4w9WgXcQ
   ```
   或其他任意短视频（建议 5-15 分钟）
5. 语言选择：`自动检测`
6. 点击「🚀 开始分析」按钮
7. 等待处理完成（约 1-5 分钟）

**预期结果：**
- ✅ 状态提示显示处理进度
- ✅ 「📊 结果展示」标签页自动切换
- ✅ 显示详细总结内容
- ✅ 显示音频转录文本（带时间戳）
- ✅ 显示关键帧图片库
- ✅ 显示视频信息卡片
- ✅ 提供下载链接（视频、音频、元数据）

**2️⃣ 本地视频上传测试**

1. 选择输入方式：`本地视频上传`
2. 点击「上传视频文件」区域
3. 选择本地 MP4/AVI/MOV 文件（建议小于 100MB）
4. 点击「🚀 开始分析」
5. 等待处理完成

**预期结果：**
- ✅ 同 YouTube 视频分析结果

**3️⃣ 智能问答功能测试**

1. 视频处理完成后，点击「🚀 启动聊天会话」
2. 等待会话状态显示「✅ 聊天会话已启动」
3. 在「你的问题」输入框输入测试问题：
   - 时间定位问题：`视频中在哪里讲了XXX？`
   - 内容总结问题：`这个视频主要讲什么？`
   - 多轮对话：`详细解释一下这个部分`
4. 点击「💬 发送」按钮

**预期结果：**
- ✅ 对话历史显示问答记录
- ✅ 系统基于视频内容回答问题
- ✅ 时间定位问题返回具体时间段
- ✅ 支持多轮对话上下文保持

## 🔧 常见问题排查

### 问题 1: 后端服务启动失败

**检查项：**
- [ ] Python 版本 >= 3.8
- [ ] 依赖包已安装（`pip install -r requirements.txt`）
- [ ] 环境变量配置正确（`.env` 文件）
- [ ] 端口 7860 未被占用

**解决方法：**
```bash
# 停止占用端口的进程
lsof -ti:7860 | xargs kill -9

# 重新启动
cd backend
./run_gradio.sh
```

---

### 问题 2: 前端服务启动失败

**检查项：**
- [ ] Node.js 版本 >= 16
- [ ] 依赖包已安装（`npm install`）
- [ ] 端口 8080 未被占用

**解决方法：**
```bash
# 清理依赖并重新安装
cd frontend
rm -rf node_modules package-lock.json
npm install

# 重新启动
npm run dev
```

---

### 问题 3: 视频处理失败

**检查项：**
- [ ] 阿里云 API 密钥配置正确
- [ ] OSS Bucket 权限正常
- [ ] 网络代理配置正确（如需要）
- [ ] 视频格式支持（MP4、AVI、MOV、MKV）

**解决方法：**

### 问题 4: 聊天功能无响应

**检查项：**
- [ ] 视频已处理完成
- [ ] 聊天会话已启动
- [ ] LLM API 配置正确（QWEN_API_KEY）
